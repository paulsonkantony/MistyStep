# Building the "Paste from PC" Shortcut

**What is a Shortcut?** A Shortcut is a small set of steps you create in Apple's **Shortcuts** app, which comes with every iPad and iPhone. Once created, it runs with one tap. "Paste from PC" asks your PC for whatever you last copied there and puts it on the iPad's clipboard, ready to paste.

**What is the setup code?** The pairing page shows a code starting with `MS1.`. It tells the Shortcut where your PC is, and holds a private key that lets this iPad in. You paste it into the Shortcut's first action (step 1 below) and do not need it again unless you re-pair.

The Shortcut cannot be generated by code, so it is built once by hand on an iPad (or iPhone) and then shared by iCloud link. This sheet lists every action in order. It takes about 15 minutes.

Action names are from iPadOS 18. If a name differs on your version, search for the closest match in the action list.

**Shortcut version: 1.** This number is sent in the `X-MistyStep-Shortcut` header. When you change the Shortcut, increase it here and in step 9.

## Before you start

- Install Misty Step on the PC and pair this iPad from **Pair a device...** in the tray menu. Keep the pairing page open in Safari: you will copy the **setup code** from it.
- On the iPad, open the **Shortcuts** app, tap **+**, and name the new shortcut **Paste from PC**.

Tip: after adding an action, tap a blue placeholder to fill it in. To insert a variable, tap the field, then choose the variable above the keyboard (or tap **Select Variable**).

## Actions

### Read the setup code

1. **Text**. Paste the setup code from the pairing page (it starts with `MS1.`).
2. **Split Text**. Input: *Text* (from step 1). Separator: **Custom**, type a single `.` (period).
3. **Get Item from List**. Get **Item At Index**, index `2`, from *Split Text*.
4. **Base64 Encode**. Tap **Encode** and change it to **Decode**. Input: *Item from List*.
5. **Get Dictionary from Input**. Input: *Base64 Encoded* (the decoded result).
6. **Set Variable**. Name: `Config`. Input: *Dictionary*.
7. **Get Dictionary Value**. Get **Value** for key `u` in `Config`. Then **Set Variable** `BaseUrl` to *Dictionary Value*.
8. **Get Dictionary Value**. Get **Value** for key `t` in `Config`. Then **Set Variable** `Token` to *Dictionary Value*.

### Decide the mode

The Shortcut runs in one of two modes:
- **Manual** (no input): always fetches the current item and shows a notification.
- **auto** (input `auto`): used by the optional automation. It fetches only an item this iPad has not received, and shows no notifications.

9. **If**. *Shortcut Input* **is** `auto`.
   - **Text** `1`, then **Set Variable** `New` to *Text*.
   - **Text** `1`, then **Set Variable** `Quiet` to *Text*.
   - **Otherwise**
   - **Text** `0`, then **Set Variable** `New` to *Text*.
   - **Text** `0`, then **Set Variable** `Quiet` to *Text*.
   - **End If**

   When you first insert *Shortcut Input*, Shortcuts adds a **Receive** line at the top of the editor. Set it to receive **Text** from **Nowhere**, and **If there's no input: Continue**.

### Ask the PC

10. **Text**. Type: *BaseUrl* `/v1/meta?new=` *New*. There are no spaces, so it reads like `http://100.101.102.103:45654/v1/meta?new=0`.
11. **Get Contents of URL**. URL: *Text* (from step 10). Tap **Show More**:
    - Method: **GET**
    - Headers: add two.
      - `Authorization` = `Bearer` + one space + *Token*. The value must look like `Bearer abc123...`, with exactly one space after the word Bearer and none before it.
      - `X-MistyStep-Shortcut` = `1`
12. **Get Dictionary from Input**. Input: *Contents of URL*. Then **Set Variable** `Meta` to *Dictionary*.

### Errors

New actions always go to the bottom. To put one inside an **If**, press and hold it and drag it between **If** and **Otherwise**. Every **If** below leaves its **Otherwise** empty.

13. **Get Dictionary Value**. Get **Value** for key `error` in `Meta`.
14. **If**. *Dictionary Value* **has any value**. Inside it:
    - **Get Dictionary Value**. Get **Value** for key `message` in `Meta`.
    - **Show Alert**. Message: *Dictionary Value*. Turn **Show Cancel Button** off.
    - **Stop This Shortcut**

### Copy the item

The blocks below are flat, with no If inside another If. Each one sets a `Note`, and a single notification at the end shows it unless the Shortcut runs quietly.

15. **Get Dictionary Value**. Key `type` in `Meta`. Then **Set Variable** `Type`.
16. **Get Dictionary Value**. Key `pc` in `Meta`. Then **Set Variable** `PC`.
17. **Text** `Nothing new on ` *PC*. Then **Set Variable** `Note`.
18. **If**. `Type` **is** `text`. Inside it:
    - **Get Dictionary Value**. Key `text` in `Meta`.
    - **Copy to Clipboard**. Input: *Dictionary Value*.
    - **Text** `Text copied from ` *PC*, then **Set Variable** `Note`.
19. **If**. `Type` **is** `image`. Inside it:
    - **Get Dictionary Value**. Key `id` in `Meta`.
    - **Text**. *BaseUrl* `/v1/data?id=` *Dictionary Value*.
    - **Get Contents of URL**. URL: *Text*. Method **GET**, with the **same two headers** as step 11.
    - **Copy to Clipboard**. Input: *Contents of URL*.
    - **Text** `Image copied from ` *PC*, then **Set Variable** `Note`.
20. **If**. `Quiet` **is not** `1`. Inside it:
    - **Show Notification**. Message: *Note*.

## First run

Run the Shortcut once from the editor (the ▶ button). iPadOS asks for permission to connect to the PC's address: choose **Always Allow**. The pairing window on the PC then shows **Paired**.

## Ways to run it

- Home Screen: in the Shortcuts app, long-press **Paste from PC**, then **Share**, then **Add to Home Screen**. A Home Screen widget, the Dock and a Control Center control also work.
- Spotlight with a hardware keyboard: Cmd+Space, type "Paste", Return.
- Siri: "Paste from PC".

## Optional: near-automatic mode

In Shortcuts: **Automation**, then **+**, then **App**. Choose the apps you paste into, tick **Is Opened**, and choose **Run Immediately**. Add one action, **Run Shortcut** *Paste from PC*, and set its input to the text `auto`. The iPad clipboard then changes only when the PC holds an item this iPad has not fetched.

## Re-pairing (new PC name, port or address)

Pair again from the tray menu, then open the Shortcut and replace the setup code in the first **Text** action (step 1) with the new one.

## Sharing the Shortcut (maintainers)

1. Add an import question so people paste their own code when they install it: in the editor, open the shortcut's **Details** (ⓘ), then **Setup**, then **Import Questions**, then **Add Question**. Pick the Text field from step 1, with the question "Paste the setup code from the Misty Step pairing page".
2. **Clear the Text action in step 1** so no real setup code is shared. Anyone with the link can read the Shortcut's contents.
3. **Share**, then **Copy iCloud Link**. Put the link in the app's `shortcutUrl` default and in the README.
4. iCloud links have failed before, so keep this sheet (with screenshots) as the fallback.
